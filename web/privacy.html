Privacy

Last updated 15 September 2026.

No Rewrite Better servers

The Chrome extension and macOS app have no account system and no backend of ours. We do not receive, store, or log the text you rewrite.

API keys

Your Groq API key stays on your device. In Chrome it is saved with chrome.storage.sync. On Mac it is stored in Keychain. This website never asks for a key.

Where text goes

When you run Rewrite, Format, or Reply, the selected text and your options are sent from your device to Groq’s API (api.groq.com). Groq’s own privacy policy applies to that request.

Chrome permissions

The extension can run on any site so the inline panel and keyboard shortcut work wherever you write. It also needs storage (for the key), contextMenus, activeTab, and scripting. Host access includes api.groq.com.

macOS permissions

The Mac app asks for Accessibility so it can read the current text selection. You can deny that permission; the panel still opens, but it will not capture selected text automatically.

This website

The download site is static files on Vercel. Language preference is stored in your browser (localStorage). We do not run analytics on this page unless Vercel’s platform logs apply to HTTP requests.

Contact

Questions: open an issue on the GitHub repository.
