How to update

Install the new version over the current one. Your API key and settings stay.

Mac with Homebrew

The first time, run these three commands:

brew tap cvthang56th2/rewrite-better
brew trust cvthang56th2/rewrite-better
brew install --cask rewrite-better

After that, update with brew upgrade --cask rewrite-better.

The first open can ask you to right-click Rewrite Better in Applications and choose Open.

Mac from the DMG

Download the latest DMG from this site and drag Rewrite Better into Applications, replacing the app already there.

Windows

From version 1.0.8, the app asks when you open it. You can also choose Check for Updates in the tray menu or in Settings.

If you installed an older build, download the new installer once and run it over the current app. Later versions then update inside the app.

Windows may show a SmartScreen warning on unsigned builds: More info, then Run anyway.

Chrome

  1. Download the new zip from the homepage.
  2. Unzip it into the same folder that is already loaded in Chrome.
  3. Open chrome://extensions and click Reload.

If you remove the extension, or load a different folder, Chrome treats it as a new extension and the saved API key is gone.
